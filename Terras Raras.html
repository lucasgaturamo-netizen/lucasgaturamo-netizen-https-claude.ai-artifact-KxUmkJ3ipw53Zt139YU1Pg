Como subir no GitHub

  1. Extraia o zip e entre na pasta terras-raras.
  2. Em github.com, clique em New repository, dê o nome terras-raras e crie o repositório vazio, sem README.
  3. No terminal, dentro da pasta, rode:
bash
git init
git add .
git commit -m "Primeira versão do site Terras Raras"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/terras-raras.git
git push -u origin main

Se preferir não usar o terminal, crie o repositório e use Add file → Upload files para arrastar os arquivos. Marque a opção de mostrar arquivos ocultos para que a pasta .github também suba.

Publicar o site online (GitHub Pages)

  1. No repositório, vá em Settings → Pages.
  2. Em Source, escolha GitHub Actions.
  3. Depois do push, a aba Actions mostra o deploy rodando.
  4. O site fica em https://SEU-USUARIO.github.io/terras-raras/.

Antes de entregar

No README.md, troque SEU-USUARIO pelo seu usuário do GitHub e SEU NOME pelo seu nome. Eu não adicionei uma licença, porque não sei qual você prefere. Se quiser, o GitHub cria uma pelo botão Add file → Create new file, digitando LICENSE no nome.
